## 2026-04-28 - Hardcoded TinyURL API Token Fixed (BYOK architecture)
**Vulnerability:** A hardcoded `TINYTOKEN` API token was present in `src/app-settings.js` in plaintext, which is a critical security vulnerability and violates the Bring Your Own Key (BYOK) architecture principles. It was used in `src/app.js` to create short URLs.
**Learning:** Hardcoded API secrets embedded in client-side source code can easily be discovered and misused by malicious actors, potentially leading to unauthorized access, resource exhaustion, or financial impact for the token owner.
**Prevention:** External API tokens, especially for integrations without user-facing input UIs (like TinyURL), should be retrieved via environment variables (e.g., `import.meta.env.VITE_TINYTOKEN` using Vite) rather than hardcoded in the codebase. Additionally, features dependent on external APIs should implement a graceful fallback (like providing the long URL) when the environment token is missing, ensuring the core functionality is not disrupted.
