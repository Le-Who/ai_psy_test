## 2024-05-18 - [CRITICAL] Remove Hardcoded TinyURL API Token
**Vulnerability:** A hardcoded TinyURL API Token (`TINYTOKEN`) was present in `src/app-settings.js` and used in `src/app.js` for shortening duel links. This exposed the secret to anyone viewing the source code of the application.
**Learning:** Hardcoding secrets directly in client-side code is a critical vulnerability as it exposes the secret to unauthorized access and potential abuse. Even if the service is a low-risk integration, secrets should never be embedded in the repository. The Bring Your Own Key (BYOK) model used elsewhere in the application for AI APIs wasn't consistently applied.
**Prevention:** Always rely on secure secret management practices. For client-side applications where a backend server is not available to proxy requests securely, prompt the user for their own token and store it securely in `localStorage` rather than hardcoding it into the application. Ensure any such tokens are omitted from source control and code reviews check for leaked secrets.
