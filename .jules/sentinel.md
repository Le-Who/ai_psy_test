## 2026-07-18 - [Hardcoded Secret & Unexported Constant Anti-Pattern]
**Vulnerability:** A hardcoded API key (TINYTOKEN) was found in src/app-settings.js. Furthermore, it was implemented as an unexported constant that src/app.js attempted to access implicitly, violating module encapsulation and leading to potential ReferenceErrors while exposing the secret in the source code.
**Learning:** Hardcoding secrets as unexported constants not only exposes sensitive data but also creates brittle dependencies across modules that rely on implicit global scope or flawed `typeof VAR !== 'undefined'` checks. Vite projects should leverage `import.meta.env.VITE_VAR_NAME` for safe, build-time environment variable injection.
**Prevention:** Never hardcode secrets in source code. Always use environment variables (e.g., `.env` files with `VITE_` prefixes for client-side) and access them via the framework's designated configuration interface (e.g., `import.meta.env`). Enforce strict module encapsulation by explicitly exporting/importing required constants.
